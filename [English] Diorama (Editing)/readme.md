# Diorama
> RPG campaign inspired by The 100, Shadowrun and Arknights.
### Details
- Three players, happening through Discord.
- A total of 12 sessions happened since the beginning.
- I created an entire original hard magic system for this campaign. If you are curious about it, send me a message so we can talk about. Once the campaign is finished, I'll write a document sharing everything about.
- Since "Eclipse", all sessions got posters or teasers made with Adobe suite. All of them were made by me by using a combination of material avaliable on the internet and original compositions.
### What I learned?
This project improved my communication, editing and game design skills. Having to think about so many possibilities to account for different interactions from the players with the system lead me to have to iterate and improve my original idea and balance it correctly.
### What I would do differently?
Would make more quests to have a buffer for later.
