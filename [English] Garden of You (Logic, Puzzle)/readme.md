# Garden of You
> Prototype of a puzzle game inspired by Neuron Riddle and The Witness.
### Details
- This project was paused recently, in favor to focus at other, more pressing projects.
- This project have 3 testers on Discord.
- The main philosophy is to teach people the skills necessary to solve puzzles instead of expecting them to have those.
- The first project I made a design document (Colors, Feelings and LevelDesign).
### What I learned?
This project specifically teached me how to make effective documentation I can use to guide myself through creative decisions.
### What I would do differently?
Add some sort of index, so I can see a summary of all levels.
