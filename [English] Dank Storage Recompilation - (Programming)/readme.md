# Recompilation (of Dank Storage)
> A simple project I did of recompilation of a Minecraft mod (Dank Storage) applying and testing a pull request (136dbc8d4204c60a41ced6e44baa6b188151f213) that was rejected because the mod isn't supported anymore for a lower version. This pull request fixes a bug the mod has at 1.12.2 where the keybinds to change the mode of the Dank don't work.
### Details
- Most of the project involved configuration, but it was a good chance to experiment with more advanced Git commands like cherry-pick, and also with more advanced Gradle configuration.
### What I learned?
How powerful Git actually is.
