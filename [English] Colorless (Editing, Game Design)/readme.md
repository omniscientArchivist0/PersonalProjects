# Colorless
> RPG campaign based on MTG (Magic the Gathering).
### Details
- Five players, will happen through Discord, Roll20 and Tabletop Simulator.
- The players will actually be playing MTG matches as part of the combat system.
- Yet to begin (August 16)
### What I learned?
This project is a big test of Game Design and involves a lot of knowledge about MTG, about different balancement metrics and how does rounds of testing influences the final result and how to learn to let go from ideas that look cool but they aren't.
### What I intend to do?
Running more rounds of testing before actually having the first sessions.
