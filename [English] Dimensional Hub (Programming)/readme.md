# Dimensional Hub
> A project inside MeatballCraft (Minecraft Modpack). It represents a way to travel to another worlds/dimensions.
### Details
- Longest personal project I ever worked on, taking a month to finish.
- It involves programming in two different languages (Lua and SFM4) and logical circuits (using ProjectRed).
- It can be reproduced and adapted to your own world.
### What I learned?
This project led me to learn the fundamentals of Lua, and teached me the value of being able to prototype your ideas before committing to them.
### What I would do differently?
I probably would have done the structure first and only later try to make the logic (to avoiding moving too much stuff).
